# StudyToTech
Sistema desenvolvido para o Projeto Integrado Multidisciplinar (PIM IV) do curso de Análise e Desenvolvimento de Sistemas da UNIP.

O projeto consiste no desenvolvimento de uma aplicação para a empresa fictícia **StudyToTech**, voltada à comercialização e gerenciamento de produtos de tecnologia, como computadores, notebooks, tablets e acessórios.

---

## 📌 Sobre o projeto

O sistema tem como objetivo oferecer funcionalidades relacionadas ao gerenciamento de:

- Usuários;
- Perfis de acesso;
- Produtos;
- Categorias;
- Pedidos;
- Itens dos pedidos;
- Status dos pedidos;
- Estoque;
- Movimentações de estoque.

O projeto é desenvolvido de forma colaborativa, utilizando Git e GitHub para controle de versão e Docker para padronização do ambiente do banco de dados.

---
